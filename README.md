# fltouch V2

FL Studio MIDI scripts for the Behringer X-Touch + extender(s) (Mackie Control Universal) MIDI controllers, completely rewritten from the official scripts by Image-Line.

Version 2 focuses heavily on being more hands-off your keyboard and mouse and becoming a true DAW controller.

## ✨ Notable features

- Use multiple extenders, and position them in various ways
- Colored scribble strips allow you to read your session at a glance
- Control FX plugins and FX plugin parameters
- Control Channel Rack plugins and Channel Rack plugin parameters
- Add plugins from the hardware
- Rename and recolor tracks without touching the mouse
- Improved knob resolution and acceleration
- Improved meter accuracy
- Auto channel selection when touching a fader
- A genuinely useful jog wheel with automatic window focus: seeking by default, but also scrubbing, zooming, tempo, browsing...
- The Menu (a.k.a. Flip) button can now be used to bring up a menu with extra functions and utilities in certain modes.
- Ability to make custom configurations per plugin (reorder & color parameters)

*Note: The old "free mode" has been removed, as it was replaced by the Channel Rack. If you still want to manually control plugins with "link to controller", you can use the faders in the plug-in mode to do so.*
